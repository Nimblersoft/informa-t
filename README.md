# informa-t

informa-t is a proposed MediaHack II MVP for journalists and fact-checking teams to examine electoral-information claims against auditable primary sources. It is an editorial assistant, not an autonomous fact-checking publisher.

## Status

Documentation-only bootstrap. The PRD is being refined before any implementation plan or application code is created.
